🇪🇹 Ethio-Mart

A Modern Ethiopian Marketplace Web Application

Ethio-Mart is a responsive e-commerce frontend designed to provide a clean and convenient online shopping experience. The project combines a modern marketplace interface with practical shopping features, Ethiopian Birr (ETB) pricing, and responsive layouts for mobile, tablet, and desktop users.

🌐 Live Demo: https://graviton25.github.io/Ethio-Mart/

---

📌 About the Project

Ethio-Mart is a student-developed web project focused on building a practical marketplace interface using fundamental web technologies.

The project was designed with an emphasis on:

- Clean and structured user interfaces
- Responsive web design
- Simple and understandable code
- Interactive shopping features
- Practical e-commerce functionality
- A foundation that can later be connected to a real backend

🚀 Getting Started

Run Locally

Clone the repository:

git clone https://github.com/Graviton25/Ethio-Mart.git

Enter the project folder:

cd Ethio-Mart

Then open:

index.html

in your browser.

No framework or build tool is required for the current frontend version.

📱 Responsive Design

Ethio-Mart is designed to work across different screen sizes:

- 📱 Mobile
- 📲 Tablet
- 💻 Laptop
- 🖥️ Desktop

The interface adapts its navigation, product grid, cards, and content sections according to the available screen size.

🎯 Project Goal

The goal of Ethio-Mart is to develop practical software-development experience while building a realistic marketplace application from the ground up.

The project also serves as a foundation for learning how a frontend application can eventually communicate with a backend, database, payment services, maps, and other APIs.

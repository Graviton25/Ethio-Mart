# Ethio-Mart

A responsive Ethiopian marketplace frontend built with plain HTML, CSS, and JavaScript.

## Project structure

- `index.html` — page structure and content
- `style.css` — layout, responsive design, theme, and animations
- `script.js` — product data, filtering, cart, favorites, modal, and assistant logic

## Run locally

Open `index.html` in a browser. No build tool is required for the frontend.

## Notes

The checkout, Google Maps, payment, and AI features are prepared as frontend interfaces and can be connected to a backend later.
